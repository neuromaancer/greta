# Standalone Pure generation in Greta

Pure is the active dialogue condition. The existing opening is fixed; subsequent
facilitator acts and utterances are selected/generated by the LLM. Patient
utterances and stage estimates also use that service. Generation finishes a
bounded episode before Greta replays it; this is not token streaming or live
per-step animation.

## Code and private assets

`integrations/gmit/pure/` contains the necessary MIT-licensed GMIT logic, ported
from revision `f2bb22d22d8a64c9404365426450801b28d33a66`:

| Component | Greta module |
| --- | --- |
| Act selection, stage estimation, round-robin episode, row validation | `episode.py` |
| Patient personas, OPEN v2, context and response validation | `patient.py` |
| Facilitator language generation | `therapist_nlg.py` |
| Act/type definitions and shared text/JSON helpers | `taxonomy.py`, `text.py`, `json_utils.py` |
| Native Ollama HTTP transport | `ollama.py` |
| Local asset loading and source-file provenance | `generation.py` |

The port retains the MIT notice and package license. Original generic prompts,
context windows, 28-word patient/32-word therapist limits, fixed opening,
readiness-disabled configuration, and F-A-B round-robin semantics are retained.
The original scheduler is represented by its narrow Pure row validator; this
path does not instantiate the RL environment. Source hashes and the current
package hash are recorded with each generated episode.

The fifteen original patient few-shot pairs are data, kept only at ignored
`integrations/gmit/local/pure-assets/patient-fewshot.json` with a private copy
receipt. The loader requires exactly fifteen nonempty input/output pairs before
contacting Ollama. A different machine needs its own authorized copy of this
asset; cloning the public repository alone is insufficient. Use
`--fewshot-asset /absolute/path/to/patient-fewshot.json` for another location.
No prompts, examples, source rows, or transcripts are written into public
verification records. The private GMIT checkout was inspected read-only.

## Generate, then replay

In a WSL terminal, start the existing Ollama service in one terminal:

```sh
cd '/mnt/c/Users/alafate abulimiti/research/workspace/greta'
bash integrations/gmit/start_ollama.sh
```

Then generate in another WSL terminal. Python 3.10+ and the standard library are
sufficient; the existing Pure virtual environment is also usable.

```sh
cd '/mnt/c/Users/alafate abulimiti/research/workspace/greta'
PYTHONDONTWRITEBYTECODE=1 python3 -m integrations.gmit.run_pure \
  --patient-turns 4 \
  --theme 'Reducing red meat' \
  --session-id "pure-$(date +%Y%m%d-%H%M%S)" \
  --timeout-seconds 600
```

There is no `--gmit-root` argument. `GMIT_ROOT` is not used. The existing local
model is `qwen3:4b-instruct-2507-q4_K_M`, with context 8192, output limit 256 and
seed 42. The service must expose that exact model at the configured loopback
endpoint (default `http://127.0.0.1:11434`). No automatic model download occurs.
Native Ollama retains the source path's omission of the vLLM-only
`response_format` argument. This is an engineering configuration, not an exact
replication of the original research setup.

The command prints the ignored bundle paths: `events.jsonl`, `replay.xml`, and
`receipt.json`. Four patient turns produce seven utterances; two patient turns
produce a short four-utterance F-A-B-F episode. The receipt keeps source rows,
asset identity, selected pair, source/package provenance, seed, model identity,
and generation settings. Failures do not silently substitute RL or a fixture.

Run the resulting `replay.xml` through Windows PowerShell with
`greta_2.1\bin\GMIT\Start-GMIT.ps1 -Replay <absolute Windows path>`.
Add `-MeaningMiner` for semantic gestures. Keep MODIFF disabled. See
[SUBTITLES.md](SUBTITLES.md) for the full replay/recording commands. Ollama can
be stopped before replay; the movie encoder also requires no model service.
